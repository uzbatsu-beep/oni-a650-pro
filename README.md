# ONI A650M — Инженерный конфигуратор PRO 2.0 (Rust + Tauri v2)

Нативное десктопное приложение для пусконаладки, мониторинга и конфигурирования преобразователей частоты **ONI A650M** (ред. 3, 617 параметров) по протоколу **Modbus RTU (RS-485)**, написанное на **Rust (`a650_core`) + Tauri v2**.

[Дорожная карта разработки и стендовой приёмки](ROADMAP.md)

## Ключевые возможности

- **Прямой обмен по RS-485 (`serialport`) + встроенный симулятор**: постоянный дескриптор COM-порта с настраиваемой скоростью (`4800..115200` бод, `F15.00`), форматом кадра (`8N2`, `8E1`, `8O1`, `8N1`, `F15.01`) и адресом `Slave ID` (`F15.02`), автопоиском параметров связи и поодиночным опросом `FC03 (count=1)`.
- **Modbus TCP/IP (MBAP)** для шлюзов, принимающих Modbus TCP и выполняющих преобразование на RS-485. Введите IP, TCP-порт (обычно 502), Unit ID привода и таймаут ответа (по умолчанию 1000 мс). Проверка связи читает один holding-регистр U00.00. Журнал показывает реальный заголовок MBAP, включая идентификатор транзакции.
- **RTU over Ethernet** для прозрачного TCP-шлюза. Укажите IP, TCP-порт шлюза и Modbus-адрес ПЧ. В TCP передаются кадры RTU с CRC. Параметры последовательной линии настраиваются на шлюзе. Подключение подтверждается чтением U00.00.
- **Файлы профиля**. «Открыть профиль .ods…» заменяет подготовленные уставки значениями из выбранного файла. Измерения текущего сеанса сохраняются отдельно. Для записи профиля и CSV доступны системные диалоги Windows с выбором каталога и имени.
- **Каталог параметров (617 позиций)** — группы `F00–F20`, `F22`, `H00` и мониторинг `U00–U01`, сквозной поиск, фильтр отличий (`Diff`), чтение группы `FC03` и одиночная запись `FC06` в RAM. Доступность адресов зависит от модели и прошивки.
- **SafetyGuard**: режим «Только чтение» по умолчанию, белый список допустимых адресов, блокировка записи параметров с атрибутом `× Только СТОП` при работающем двигателе, запрет авто-повторов при таймауте записи (`WriteOutcomeUnknown`) и журнал событий сеанса.
- **Интерактивный клеммник и мастера ПНР**: SVG-клеммник для габаритов `1.5–2.2 кВт (Компакт)` и `3.7–450 кВт (Полный)`, переключатели V/mA, мастер ПИД-регулятора (`F13`) и насосного каскада (`H00`), декодер 45 кодов аварий (`Err01..Err40`, `EXC01..EXC11`) и калькулятор кадров Modbus RTU с `CRC-16`.
- **Темы оформления**: `ONI Orange`, `Nord`, `Dracula`, `Monokai` (Светлая / Темная).

## Сборка и тестирование

### 1. Модульные тесты ядра `a650_core` (без GUI)
```bash
cd src-tauri
cargo test --locked --no-default-features
```

### 2. Сборка релизного приложения (Windows / Linux)
```bash
cd src-tauri
cargo build --locked --release --features tauri/custom-protocol
```
Для Windows x64 (MSVC) готовый файл — `src-tauri/target/release/oni-a650-pro.exe`. Версия Rust закреплена в `rust-toolchain.toml`, зависимости — в `src-tauri/Cargo.lock`. Интерфейс и стили входят в EXE. На стендовом ПК требуется установленный Microsoft Edge WebView2 Runtime. Сборки PR доступны в GitHub Actions как артефакт `oni-a650-pro-windows-x64`.

### Проверка чтения на стенде

1. Задайте режим RS‑485, порт и адрес ПЧ, нажмите «Подключить». Для проверки телеметрии оставьте включённым режим «Только чтение».
2. Сверьте U00.02 (выходное напряжение), U00.03 (выходной ток) и U00.06 (напряжение звена DC) с панелью ПЧ. При наведении на число отображается исходное значение регистра (`raw`). Достоверный ноль отображается числом.
3. До первого ответа, при потере связи или по истечении пяти секунд с последнего подтверждённого чтения канал показывает «—». После переподключения показания заполняются заново по мере прихода ответов. Для сравнения зафиксируйте модель и прошивку ПЧ, COM-порт, slave ID и показания панели.
