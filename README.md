# ONI A650 / A650M — Инженерный конфигуратор PRO 2.0 (Rust + Tauri v2)

Нативное десктопное приложение для пусконаладки, мониторинга и конфигурирования преобразователей частоты **ONI A650** (ред. 1, 531 параметр) и **ONI A650M** (ред. 3, 617 параметров) по протоколу **Modbus RTU (RS-485)**, написанное на **Rust (`a650_core`) + Tauri v2**.

## Ключевые возможности

- **Прямой обмен по RS-485 (`serialport`) + встроенный симулятор**: постоянный дескриптор COM-порта с настраиваемой скоростью (`4800..115200` бод, `F15.00`), форматом кадра (`8N2`, `8E1`, `8O1`, `8N1`, `F15.01`) и адресом `Slave ID` (`F15.02`), автопоиском параметров связи и поодиночным опросом `FC03 (count=1)`.
- **Полный верифицированный каталог параметров (617 позиций)**: группы `F00–F20`, `H00` и мониторинг `U00–U01`, сквозной поиск, фильтр отличий (`Diff`), чтение группы `FC03` и запись `FC06` в RAM (`0x0000..`) и EEPROM (`0x8000..`).
- **SafetyGuard**: режим «Только чтение» по умолчанию, белый список допустимых адресов, блокировка записи параметров с атрибутом `× Только СТОП` при работающем двигателе, запрет авто-повторов при таймауте записи (`WriteOutcomeUnknown`) и журнал транзакций `audit.jsonl`.
- **Интерактивный клеммник и мастера ПНР**: SVG-клеммник для габаритов `1.5–2.2 кВт (Компакт)` и `3.7–450 кВт (Полный)`, переключатели V/mA, мастер ПИД-регулятора (`F13`) и насосного каскада (`H00`), декодер 45 кодов аварий (`Err01..Err40`, `EXC01..EXC11`) и калькулятор кадров Modbus RTU с `CRC-16`.
- **Темы оформления**: `ONI Orange`, `Nord`, `Dracula`, `Monokai` (Светлая / Темная).

## Структура репозитория

```text
.
├── .github/workflows/
│   └── rust-tauri-release.yml  # CI: cargo test + сборка релизов для Windows и Linux
├── .gitignore
├── LICENSE                     # MIT License
├── README.md
├── ui/
│   └── index.html              # Веб-интерфейс конфигуратора (вшивается в бинарник)
└── src-tauri/
    ├── Cargo.toml              # Конфигурация крейта oni-a650-pro (a650_core)
    ├── build.rs                # Сборка ресурсов Tauri v2 (при включенном feature gui)
    ├── tauri.conf.json         # Конфигурация окна 1440x900 и бандлера
    ├── capabilities/
    │   └── default.json        # Разрешения Tauri v2 IPC
    ├── icons/                  # Иконки приложения (icon.ico, 32x32, 128x128, icon.png)
    ├── data/
    │   ├── parameters.csv      # 617 параметров (вшиваются через include_str!)
    │   ├── registers.csv       # 50 регистров управления и мониторинга
    │   └── errors.csv          # 45 кодов аварий и исключений Modbus
    └── src/
        ├── lib.rs              # Ядро a650_core и модульные тесты
        ├── main.rs             # Tauri-команды (#[tauri::command]) и CLI-режим
        ├── addresses.rs        # Адресная арифметика F00..F20, H00 (0x4000/0xC000), U00
        ├── modbus.rs           # Кадры Modbus RTU FC03/FC06 и CRC-16/MODBUS
        ├── safety.rs           # SafetyGuard и аудит транзакций
        ├── ods.rs              # Импорт/экспорт профилей .ods (UTF-8-BOM INI)
        ├── catalog.rs          # Загрузчик встроенных CSV-таблиц
        └── actor.rs            # Потокобезопасная сессия ПЧ (RS-485 + симулятор)
```

## Сборка и тестирование

### 1. Модульные тесты ядра `a650_core` (без GUI)
```bash
cd src-tauri
cargo test --no-default-features
```

### 2. Сборка релизного приложения (Windows / Linux)
```bash
cd src-tauri
cargo build --release
```
Готовый файл появится в `src-tauri/target/release/oni-a650-pro.exe` (рядом при сборке через MinGW также находится `WebView2Loader.dll` — для переноса на другой ПК копируйте `.exe` вместе с `*.dll`).
