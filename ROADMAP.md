# Дорожная карта ONI A650M

Область проекта — Windows-конфигуратор A650M редакции 3, работа по Modbus RTU и автономная подготовка профилей. Базовая версия для этого плана включает PR №9 со списками назначения входов/выходов и кривой выходного напряжения U00.02.

| Этап | Результат | Как принять |
|---|---|---|
| Windows v0.2.0-preview.4 | Согласованные обозначения клемм, схем и параметров F04. Раздельные включение каскада H00.00 и выбор режима H00.01. Единый список значений для предпросмотра, применения и экспорта настроек мастеров | Проверить все режимы каскада, выключенные опции, нулевые значения и экспорт заводских значений при явном выборе. Применение работает в локальном профиле. Windows CI собирает EXE и открывает окно |
| Windows v0.2.0-preview.5 | Привязка запросов к подтверждённому сеансу, телеметрия направления и текущей аварии, раздельный экспорт измерений и уставок в .ods | На стенде сравнить U00.02 и частоту при реверсе с панелью ПЧ. Прочитать уставку, задать другое значение офлайн и сверить обе секции файла. После смены адреса проверить источник измерений |
| Windows v0.2.0-preview.6 | Чтение всего каталога с прогрессом и отменой, открытие и сохранение файлов, прозрачный RTU через TCP, режим настройки при нулевой выходной частоте | На ПЧ сверить F00.20–F00.22 и результат чтения полного каталога. Проверить подключение через аппаратный шлюз, сохранение и открытие .ods на Windows |
| Windows v0.2.0-preview.7 | Стандартный Modbus TCP/IP (MBAP) для шлюзов с преобразованием протокола | Сверить с OPC чтение 0x3000 и 0x2100 через EKF. Проверить совпадение Unit ID и ответов в журнале |
| Следующий этап | Снимок фактических параметров и сравнение с эталоном «После ПНР» | Последовательный FC03, выбор групп, прогресс и отмена. Частичный снимок различает прочитанное значение, недоступный адрес и пропуск. Сравнение с заводскими значениями доступно отдельно |
| Регистратор сеанса | Метки времени каждого успешного чтения, качество каналов, физические единицы, два курсора, экспорт CSV | Измерить реальный интервал опроса каждого канала на стенде; при потере связи виден разрыв, сохранённые точки воспроизводятся офлайн |
| Диагностика | История аварий U01 и архив для сервисной службы | Открыть архив на втором ПК и сопоставить сведения ПЧ, локальный журнал и ближайший замер |
| Монитор клемм | Назначение, фактическое состояние и возраст показания для DI, DO и AI | Подтвердить кодирование U00.12–U00.16 на доступных исполнениях, включая совместные состояния и отключение связи |
| Разбор переходных процессов | Триггер по событию, предыстория и совмещение двух записей | Событие привязано ко времени нового отсчёта, файлы открываются без подключения к ПЧ |

Для приёмки на оборудовании фиксируются исполнение, прошивка, адаптер, настройки связи и версия приложения. Отдельно проверяются содержимое профиля, чтение и операции записи, разрешённые действующей политикой. [Политика записи](docs/SAFETY_WRITE_POLICY.md) · [Проверка реверса](docs/REVERSE_FREQUENCY_VERIFICATION.md)
