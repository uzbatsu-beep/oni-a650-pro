# Участие в разработке ONI A650 PRO

Здесь разрабатывается Windows-конфигуратор для ONI A650 и A650M на Rust и Tauri. Перед участием прочитайте [кодекс поведения](CODE_OF_CONDUCT.md).

## Как описать задачу

Для обычной ошибки выберите шаблон «Сообщение об ошибке». Укажите версию сборки или короткий хеш коммита и опишите, что вы ожидали увидеть и что увидели. Для предложения по интерфейсу полезен конкретный сценарий наладчика и снимок экрана. Уязвимости и дефекты, способные разрешить непреднамеренную запись в привод, передавайте по [правилам приватного сообщения](SECURITY.md).

## Как подготовить изменение

Создайте ветку от актуального `main`. Ядро и транспорт расположены в `src-tauri/src/`, таблицы параметров и регистров — в `src-tauri/data/`, интерфейс — в `ui/`. Если меняете адрес, масштаб, единицу или доступ к параметру, укажите модель ПЧ и источник. Для руководства приведите редакцию и страницу, для измерения — версию прошивки, исходное значение регистра (`raw`) и показание панели, если они известны. Отдельно отметьте, что проверено на симуляторе и что проверено на приводе.

Запустить тесты ядра можно из корня репозитория.

```sh
cd src-tauri
cargo test --locked --no-default-features
```

В pull request опишите результат для пользователя и проведённые проверки. Для изменения интерфейса приложите снимок затронутого экрана, если он помогает проверить поведение. GitHub Actions запускает тесты ядра, собирает Windows EXE и проверяет открытие окна. [Сборка и проверка на стенде](README.md)
