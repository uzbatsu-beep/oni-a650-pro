# Проверка знаковой частоты ONI A650/A650M

## Предпосылка
При настройке `F15.08 = 0` (заводское значение) мониторинговый регистр `U00.00` (`0x3000`) передаёт частоту в знаковой форме: прямое вращение — положительное значение, обратное — отрицательное. `F15.08 = 1` задаёт абсолютное значение и не позволяет восстановить направление только из `U00.00`.

Источник: ONI A650, руководство по эксплуатации, раздел F15.08, стр. 124 (https://rospolus.ru/doc/chastotniki/ONI/A650/RE-A650.pdf).

## Преобразование
- В Modbus FC03 регистр передаётся как 16-битное слово (raw `u16`), независимо от смысла данных.
- При `F15.08=0` трактовать `0x3000` как `i16` в дополнительном коде, затем умножать на 0.01 Гц.
- Пример: `0xEC78` = `60536` как u16 = `-5000` как i16 = `-50.00 Гц`.
- Все остальные измерения (ток, DC, выходное напряжение) не должны быть изменены.

## Стендовая приёмка
1. На физическом ПЧ **не изменяя настройки**, считать `F15.08` (RAM 0x0F08), зафиксировать значение и модель/прошивку. Для ожидаемого реверса ниже нуля оно должно быть 0.
2. В режиме только чтения убедиться, что `U00.00` показывает 0.00 Гц при останове, +50.00 Гц при прямом вращении и -50.00 Гц при обратном. Сохранять raw и RX HEX для каждого режима.
3. Сверить числа с панелью ПЧ, а также осциллограмму: частота при реверсе ниже центральной линии 0, при прямом — выше. Ток ×3 и DC ÷10 остаются выше нуля.
4. Провести реверс, включая торможение через 0: кривая должна пересекать нуль, не отрезаться и не переходить в значения 600+ Гц.
5. Сверить направление по биту 1 регистра `0x2101` с панелью. При отключении RS-485 показания направления и текущей аварии должны перейти в «Нет данных», на осциллограмме должен появиться разрыв. При восстановлении связи дождаться новых ответов каждого канала.
6. Если `F15.08=1`, отрицательный знак из одного `0x3000` не восстанавливается. Для отрицательной частоты потребуется достоверно считанное направление (`0x2101`) либо выбор конфигурации, но автоматическая запись F15.08 не допускается.
