Проверочный выпуск ONI A650M для Windows x64.

- Клеммник показывает программное назначение DI1–DI7 из текущего профиля и коды F04. Двух- и трёхпроводные схемы ссылаются на F04.15.
- В насосном мастере H00.00 включает каскад, H00.01 выбирает один из четырёх режимов. Заполнение трубы задаётся в %/с и %, период чередования — в минутах.
- Мастера H00 и ПИД показывают инженерные значения и соответствующие raw-коды. Применение переносит показанные строки в локальный профиль. Экспорт .ods сохраняет явно выбранные значения, включая ноль и заводские значения.
- В выпуск вошли списки функций входов/выходов, кривая выходного напряжения U00.02 и действующие проверки одиночной записи FC06.

Распакуйте ZIP и запустите `oni-a650-pro.exe`. На компьютере требуется Microsoft Edge WebView2 Runtime. Для сверки загрузки приложен `SHA256SUMS.txt`.

В GitHub Actions выполняются тесты ядра Rust, тесты JavaScript, сборка EXE и проверка открытия окна. Проверка этого выпуска на физическом ПЧ предстоит.
