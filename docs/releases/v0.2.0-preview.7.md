Проверочный выпуск ONI A650M для Windows x64.

Для шлюза EKF TSX-MC-232/485 с настройкой Socket A → TCP Server → ModbusTCP выберите в конфигураторе «Modbus TCP/IP (MBAP)». Введите IP шлюза, его порт (обычно 502) и адрес ПЧ на RS-485. Начальный таймаут ответа для этого режима — 1000 мс. Скорость, чётность и число стоп-битов задаются на стороне шлюза.

Подключение проверяется чтением одного регистра U00.00 (0x3000) командой FC03. Начальное состояние «Только чтение». В полях TX/RX видны кадры TCP вместе с идентификатором транзакции. Поддержаны подтверждения FC06 и ответы-исключения шлюза. Для прозрачных последовательных серверов по-прежнему доступен «RTU over Ethernet» с CRC.

Распакуйте ZIP и запустите oni-a650-pro.exe. Требуется Microsoft Edge WebView2 Runtime. SHA256SUMS.txt содержит контрольную сумму архива. В автоматических тестах использованы программные TCP-шлюзы. Стендовая проверка этого выпуска на EKF предстоит.
