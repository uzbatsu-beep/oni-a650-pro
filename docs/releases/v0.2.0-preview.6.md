Проверочный выпуск ONI A650M для Windows x64.

- При открытии выбран RS-485. Выберите порт и нажмите «Подключить ПЧ». Тема и палитра восстанавливаются после обновления и повторного запуска.
- Для прозрачного TCP-шлюза выберите «RTU over Ethernet», укажите его IP, настроенный TCP-порт и адрес ПЧ. Шлюз должен передавать кадры RTU с CRC. Скорость и формат последовательной линии задаются на шлюзе.
- «Все группы» последовательно опрашивает 617 адресов FC03. Во время опроса отображается прогресс, повторное нажатие останавливает чтение. Успешные ответы доступны для экспорта, даже если часть регистров недоступна.
- Исправлены единицы F00.20–F00.22. В режиме настройки (2100H = 0) для записи уставок контроллер дополнительно проверяет нулевую выходную частоту и повторно подтверждает режим настройки непосредственно перед одиночной FC06.
- Диалог «Сохранить как» позволяет выбрать папку и имя CSV или профиля .ods. «Открыть профиль .ods…» загружает уставки из выбранного файла в редактор. Встроенный пример насосного ПИД доступен отдельно.

Распакуйте ZIP и запустите `oni-a650-pro.exe`. Требуется Microsoft Edge WebView2 Runtime. Для проверки загрузки приложен SHA256SUMS.txt. Испытания этой версии на физическом ПЧ и аппаратном TCP-шлюзе предстоят.
