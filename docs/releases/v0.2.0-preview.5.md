Проверочный выпуск конфигуратора ONI A650M для Windows x64.

- В сохранённом профиле `.ods` секция `[Parameter Read]` содержит последние успешные чтения FC03 из таблицы параметров за один сеанс. При реверсе считанная частота сохраняет знак. После отключения можно сохранить снимок с исходным адресом и портом. Новое подтверждённое подключение начинает отдельный снимок.
- В `[Parameter Set]` попадают параметры, выбранные флажком «В профиль», отредактированные вручную или применённые из мастера либо демо-профиля. Повторное чтение сохраняет подготовленную уставку. Флажок позволяет включить заводское значение или снять уставку. Перед сохранением проверяются права доступа, диапазон, шаг и код перечисления.
- В заголовке указаны модель, адрес, порт при наличии, скорость в бодах, формат кадра, транспорт и источник настроек. Поля `BaudRate`, `FrameFormat`, `Transport` и `ConnectionSource` относятся к этому конфигуратору. Совместимость настроек порта с OniDriveStudio требует проверки на образце производителя.
- Изменение параметров связи блокирует команды до подтверждения нового подключения. Направление вращения и текущая авария в режиме RS-485 берутся из телеметрии текущего ПЧ.

Распакуйте ZIP и запустите `oni-a650-pro.exe`. Требуется Microsoft Edge WebView2 Runtime. Контрольная сумма архива приведена в `SHA256SUMS.txt`.

Для проверки на стенде прочитайте U00.02, измените уставку F03.01 в редакторе и сохраните файл. Сверьте напряжение в `[Parameter Read]` с показанием ПЧ и время замедления в `[Parameter Set]` с введённым значением с учётом шага 0,1 с. Экспорт выполняется локально. Стендовая проверка этого выпуска предстоит.
