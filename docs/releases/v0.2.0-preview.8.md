Windows x64 · ONI A650M PRO

- В шапке остались логотип ONI и название конфигуратора. Кнопка «?», окно «О программе» и команда открытия репозитория удалены. В метаданных приложения больше не указываются автор проекта и адрес репозитория.
- На вкладке «Параметры» кнопка «Сохранить в EEPROM…» сохраняет выбранные рабочие значения групп F и H00. Предпросмотр показывает фактическое значение RAM, адрес назначения и исходное слово. Перед каждой записью конфигуратор сверяет значение с приводом.
- В мониторинге Modbus TCP/IP (MBAP) можно независимо выбрать способ чтения и период. На стенде оператора подтверждены опрос семи регистров с заданным периодом 50 мс и сохранение RAM в EEPROM в предшествующей сборке. Для прямого RS-485 используется одиночный опрос.

Распакуйте архив и запустите `oni-a650-pro.exe`. Для работы требуется Microsoft Edge WebView2 Runtime. Файл `SHA256SUMS.txt` содержит контрольную сумму ZIP.
